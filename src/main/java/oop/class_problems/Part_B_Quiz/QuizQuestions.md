# Part B — Quiz

## Q1. What is the time complexity for accessing an element at a known index in a one-dimensional (1D) array?

A. O(n)  
B. O(1)  
C. O(log n)  
D. O(n²)

**Answer: B. O(1)**

---

## Q2. The operation of adding a new element to a data structure is known as what?

A. Traversal  
B. Deletion  
C. Insertion  
D. Searching

**Answer: C. Insertion**

---

## Q3. When choosing an appropriate data structure for a given problem, what is the most crucial step?

A. Always selecting an array because it's simple  
B. Ignoring memory constraints to optimize for speed  
C. Matching the required operations and constraints to the strengths of different data structures  
D. Using only primitive data types to avoid complexity

**Answer: C. Matching the required operations and constraints to the strengths of different data structures**

---

## Q4. A software system stores frequently accessed calculations in a cache (extra memory) to avoid recomputing them, thereby speeding up future queries. This scenario best illustrates what concept?

A. Primitive vs non-primitive data distinction  
B. Linear vs non-linear data structures  
C. Time vs space trade-offs  
D. Big-O notation simplification

**Answer: C. Time vs space trade-offs**

---

## Q5. A function has two distinct loops. The first loop iterates m times over one input, and the second loop (not nested) iterates n times over a different input. What is the overall time complexity?

A. O(m × n)  
B. O(m + n)  
C. O(m²)  
D. O(n²)

**Answer: B. O(m + n)**

---

## Q6. In which type of data structure are elements arranged sequentially, where each element (except the first/last) has exactly one predecessor and one successor?

A. Non-linear data structure  
B. Hierarchical data structure  
C. Linear data structure  
D. Networked data structure

**Answer: C. Linear data structure**

---

## Q7. An algorithm performs a number of operations proportional to 2n + 5. According to the rules of Big-O notation, what is its simplified time complexity?

A. O(2n)  
B. O(n + 5)  
C. O(n)  
D. O(1)

**Answer: C. O(n)**

---

## Q8. Which of the following is an example of a non-primitive data structure?

A. int  
B. char  
C. boolean  
D. Linked list

**Answer: D. Linked list**

---

## Q9. For a two-dimensional (2D) array with m rows and n columns, what is the time complexity of visiting every element exactly once?

A. O(m + n)  
B. O(m × n)  
C. O(log(m × n))  
D. O(1)

**Answer: B. O(m × n)**

---

## Q10. What is the fundamental purpose of a data structure?

A. To make a program incorrect or slow  
B. To define basic variables in a language  
C. To organize, store, and access data efficiently for specific operations  
D. To exclusively manage memory allocation

**Answer: C. To organize, store, and access data efficiently for specific operations**
